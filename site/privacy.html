Morning Agent is a local-first application. The project does not receive the inbox, course, file, or account data that you collect with the app.

1. The landing website

This static website is hosted by GitHub Pages. It has no sign-up form, analytics script, advertising tracker, or project-managed cookies. GitHub may process technical information such as request data to operate and protect its hosting service. See GitHub’s Privacy Statement for its handling of that information.

2. Information stored by the local app

When you run Morning Agent, it can read the sources you enable, such as Gmail, Outlook, GitHub, Moodle, Ed Lessons, local downloads, and RSS feeds. It stores collected items, decisions, reviews, and run history in a local SQLite database (by default, .data/morning-agent.sqlite). Browser-based integrations keep their sign-in profiles in local folders. OAuth credentials are kept in local configuration or token files.

The project does not operate a cloud account for this app and does not receive this information. The software has no built-in project telemetry or analytics. Protect your computer, configuration files, OAuth tokens, and browser profiles as you would other private records.

3. Information sent to connected services

Enabled collectors make requests directly from your computer to the services you configure. Gmail access uses the read-only Gmail scope. Outlook, Moodle, and Ed Lessons are read through browser sessions. GitHub and RSS requests go to their respective services and feeds. Those providers apply their own privacy terms.

4. Optional decision providers

You can configure Laya-MLX to run locally. If you disable Laya-MLX or explicitly enable the TypeSafe fallback, Morning Agent sends the normalized item and typed decision questions to TypeSafe Jev for classification. Item text and metadata may include private email bodies, course material, or other source content. Review the provider’s terms and privacy practices before enabling a remote provider.

5. Actions and sharing

Source collection is read-only. The app can perform selected local file operations and offers approval-gated task and calendar actions. It does not send email, submit coursework, delete files, or modify Moodle or GitHub. The app does not send collected content to the Morning Agent project.

6. Your choices and deletion

Choose which sources and decision provider to enable. You can remove the local database, browser profiles, and token files from your computer to delete the associated local history and sign-in state. Check the relevant provider’s account settings if you also want to revoke connected credentials.

7. Contact

If you contact the project through GitHub Issues, your GitHub username and the information you post may be visible publicly and are handled under GitHub’s terms. Do not include passwords, tokens, email contents, or other sensitive personal information in a public issue. For privacy questions, identify the issue as a privacy request without including the underlying private data.
