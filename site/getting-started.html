A few minutes to set up

What you need

  • macOS (the project is macOS-first)
  • Node.js 20 or newer
  • Terminal, for installing and running the source
  • Optional: credentials for the services you choose to connect

Install and open the dashboard

  1. 1
    Download and unzip

    Choose Download source ZIP, then open Terminal in the extracted morning-agent-main folder.

  2. 2
    Install dependencies
    npm install
  3. 3
    Set up your local config

    Copy the example config. Add credentials only for the sources and decision provider you choose.

    cp .env.example .env
  4. 4
    Start with the offline demo
    npm run morning -- --mock

    This runs sample data without connecting to your accounts.

  5. 5
    Open the dashboard
    npm run dashboard

    Then visit http://127.0.0.1:4782 in your browser.

Using Moodle, Outlook, or Ed Lessons?

Those sources use a local Chromium browser. Install it once with npx playwright install chromium. The first run opens a browser so you can sign in yourself.

Choose your sources

Every integration is optional. Follow the setup notes in the project README for Gmail, GitHub, Moodle, Outlook, Ed Lessons, news feeds, and local files. Give the app only the access it needs.

Choose a decision provider

The app can use local Laya-MLX for typed classification decisions. You can also configure the TypeSafe Jev provider. When a remote provider is enabled, the app sends the item content and metadata needed for its decision; review the Privacy Notice before connecting personal inbox or course content.

Source code, not an installer

This download does not include a signed .app bundle. You’ll need Node.js and a few Terminal commands. The walkthrough video will be added here when it’s ready.
